# 整窗动画预览版

适用于 WinDock 0.6.0-preview.7。四种动作已经接入原生窗口动画时间线；实际画面、流畅度和应用兼容性尚未验证。

## 动作与设置

| 动作 | 默认效果 | 默认时长 |
| --- | --- | --- |
| 打开窗口 | 从对应 Dock 图标展开到窗口位置 | 240 毫秒 |
| 关闭窗口 | 短距离下移、轻微收缩并淡出 | 180 毫秒 |
| 最小化 | 整窗收向对应 Dock 图标 | 320 毫秒 |
| 恢复 | 从 Dock 图标展开到原窗口位置 | 240 毫秒 |

四种动作可分别开关，时长可在 120–600 毫秒之间调整。还可选择运动曲线、关闭下移距离、结束尺寸和淡出延后程度。隐藏到托盘使用独立开关，沿用关闭动作的外观参数；应用继续在后台运行。

打开动作包括进入普通显示过渡的新主窗口。首次启动、从后台重新显示、商店应用以及自行管理窗口显示的程序，是否进入此路径取决于 Windows 和应用行为。找不到对应图标时使用最近的 Dock 中部位置。没有可用 Dock 位置时，使用窗口底部的收放位置。

## 启用

1. 从托盘菜单退出正在运行的 WinDock，再启动完整解压目录中的 `WinDock.exe`。保留同目录的动画 DLL、启用程序、清单和许可文件。
2. 打开“Dock 设置 → 动画”，点击“启用到本次登录”。Windows 会请求管理员确认。普通 Dock 功能不要求以管理员运行。
3. 状态显示“已启用”表示组件已连接。该状态不表示动画效果或全部应用兼容性已经通过验证。

功能默认关闭。退出 WinDock 后停用新的自定义动画；同一次登录中重新启动 WinDock，可重新连接已加载的组件。注销或重启后，需要再次点击启用。本版没有安装提权启动任务或系统服务。

本版只适配 x64 Windows 的 `udwm.dll 10.0.26100.9949`，并核对完整文件 SHA-256、已加载模块标识和函数入口。仅版本号相同仍可能不兼容。Windows 更新、组件缺失、文件校验失败或权限被系统阻止时，继续使用 Windows 动画。

## 已知限制

- 仅处理普通主窗口。置顶、工具、无激活、点击穿透、小型弹窗、全屏无边框和特殊裁剪路径不使用此效果。
- 原生显示过渡或销毁过渡未创建可用时间线时，保持 Windows 的处理。应用已清空内容、受保护内容、原生首次画面尚未就绪的情况，不能保证有完整可用画面。
- 快速反向从已记录的原生当前位置继续。窗口几何发生变化、动作不匹配或记录失效时不沿用旧轨迹。连续点击、最大化恢复、跨屏落点、圆角、阴影与遮挡效果均待实际确认。
- 动画组件运行于桌面窗口管理器内部。异常可能导致桌面闪黑、DWM 重启或会话中断。Windows 更新后必须重新适配，不能靠关闭版本检查继续启用。
- 本机编译组件目前没有数字签名。来源为本仓库源码及固定版本的 MinHook。遇到 Windows 或安全软件阻止时保留拦截，不关闭防护、不添加排除规则。

本版使用 DWM 的窗口表示和完成处理，Dock 已停止调用旧截图覆盖层。不修改磁盘上的 Windows DLL，不更改原窗口透明样式，不添加捕获边框豁免。

## 回滚

关闭“整窗动画（预览）”即可停止接收新的自定义过渡，已建立的短动画由 Windows 正常结束。退出 WinDock 同样停用；异常退出或失去联系后，组件在两秒内停止接受新的过渡。

组件会在当前会话中保留，但不再定制后续动画。注销并重新登录可完全移除本次加载的组件。若桌面操作异常，使用 `Ctrl+Alt+Delete` 进入系统界面并注销；注销会关闭当前应用。

需要恢复旧版时，先退出新版，必要时注销，再启动原版本。无需替换系统文件。用户设置保存在 `%APPDATA%\WinDock`，PecoFence 布局、DeskBox 和桌面文件不由此功能修改。
