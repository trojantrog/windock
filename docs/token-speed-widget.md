# Token 输出速度

在环境的小组件列表中开启“Token 速度”，即可在 Dock 查看词脉（TokenPulse）记录的最近输出速度。词脉需要已安装并运行，WinDock 会每 2 秒读取它的本地统计记录。

数字的单位为 Token/s，计算方式为本次已完成输出的 Token 数除以本次输出耗时。它是已完成输出的估算速度，记录和显示可能有延迟。超过 60 秒没有新的有效输出时，显示“—”和“等待新输出”。有效记录的输出量为零时，显示 0.0。

将鼠标停在小组件上，可以查看模型、完成时间、输出量、耗时，以及同一模型近 30 分钟的加权均速。均速按输出量合计除以耗时合计计算；词脉保留的记录和读取上限可能使该窗口的历史不完整。

未找到词脉数据、数据库繁忙、格式不兼容或没有有效记录时，小组件会显示相应状态并继续重试。

WinDock 仅以只读方式打开当前用户的 `%LOCALAPPDATA%\TokenPulse\history.sqlite`，读取最近 30 分钟内至多 10,000 条记录中的时间、输出量和模型信息。读取会包含 SQLite 已提交的 WAL 记录。WinDock 不读取聊天正文、提示词、认证信息或 Codex 会话文件，不启动另一个词脉进程，也不修改词脉数据。

本组件已按 TokenPulse 0.1.5 的统计格式验证。后续版本若变更格式，可能需要更新 WinDock。
