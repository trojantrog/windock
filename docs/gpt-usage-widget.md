# GPT 用量

在环境设置中启用“GPT 用量”，即可查看已登录 Codex 的 ChatGPT 账号额度。需要已安装 Windows 版 Codex，并在其中完成 ChatGPT 登录。API 密钥的用量单独计费，不会显示为此处的账号额度。

数值表示当前窗口已经使用的比例，细进度条与数值一致。组件按服务实际提供的窗口显示 5 小时、7 天数据：只提供一项时使用单列，同时提供两项时使用双列。未提供的窗口不会显示成 0%。将鼠标停在组件上，可以看到每个窗口精确到秒的本地重置日期时间、上次获取时间和数据年龄。

组件默认使用宽形，与活动和网速组件保持相同的中性色样式。宽形最低高度为 64 DIP，主数值为 22 DIP，副字为 13 DIP；应用图标的尺寸仍由原来的图标设置控制。也可通过右键菜单明确选择方形。

额度在后台每 90 秒刷新一次，各环境和屏幕共享同一份内存缓存。一次查询最多等待约 12 秒，随后关闭本次查询的子进程。连接失败时可保留上一次数据，并以“过期”标记；超过 5 分钟或已到重置时间的数据也会标记过期。组件不会根据重置时间推算新的 0% 用量。未登录、客户端缺失、额度不受支持、超时或获取失败时会显示对应状态。

数据通过官方 Codex 客户端的本地标准输入输出接口获取，固定使用 `%LOCALAPPDATA%/OpenAI/Codex/bin/codex-stable.exe`。组件只发出初始化、读取账号登录方式和读取额度请求，不请求生成内容，也不读取对话。WinDock 不直接读取、保存或输出账号凭证和账号标识，额度缓存随程序退出清除。官方 Codex 客户端正常运行时仍可能更新自己的运行日志、缓存或登录状态。

安装路径不符合上述位置、客户端协议变化或服务未提供 5 小时和 7 天窗口时，组件会显示无法获取额度。可先在 Codex 中确认登录状态并更新客户端，随后等待自动刷新。

接口说明：[官方 Codex App Server 文档](https://learn.chatgpt.com/docs/app-server)。
